# UniEmoji

**统一的 emoji 协议，用一套语义连接不同的表情。**

Same meanings, any face.

一句话解释：UniEmoji 让 AI 用上丰富多样的表情包。通过统一 emoji 的语义，关联不同风格的表情图片，AI 回复中的 emoji 就能呈现为对应的表情包，让同一种表达拥有不同的面孔。

[访问官网](https://hellodigua.github.io/UniEmoji/)

## 生态实现
